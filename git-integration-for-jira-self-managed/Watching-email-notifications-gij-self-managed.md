The user will get notifications when watching an issue or repository. The user will receive repository commit notifications if that repository is being watched by the user. If the user watches an issue, any commit related to the issue will be sent to that user as notifications.

> **Info:** The user will get notifications from own commits if the My Changes setting in the <img src='/wp-content/uploads/gij-profile-icon.png' style='margin:0 3px' /> User Profile ➜ <b>Preferences</b> is set to <b><i>Notify me</i></b>.

> **Tip:** The user can watch repositories in the Repository Browser. Select a repository under the <b>Git</b> menu then click the Start watching label to activate repository email commit notifications.<br>
